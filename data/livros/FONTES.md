# Textos integrais — fontes e situação legal

Todos os textos abaixo estão em **domínio público no Brasil** (autor falecido
há mais de 70 anos, Lei 9.610/98, art. 41). Importados para `Book.textoCompleto`
por `npm run seed:books`, para leitura offline dentro do sistema.

| Arquivo | Obra / Autor (falecimento) | Fonte |
|---|---|---|
| `dom-casmurro.txt` | Dom Casmurro — Machado de Assis (†1908) | Project Gutenberg #55752 (boilerplate removido) |
| `memorias-postumas-bras-cubas.txt` | Memórias Póstumas de Brás Cubas — Machado de Assis (†1908) | Project Gutenberg #54829 (boilerplate removido) |
| `iracema.txt` | Iracema — José de Alencar (†1877) | Project Gutenberg #67740 (boilerplate removido) |
| `o-cortico.txt` | O Cortiço — Aluísio Azevedo (†1913) | Wikisource pt (23 capítulos) |
| `o-navio-negreiro.txt` | O Navio Negreiro — Castro Alves (†1871) | Wikisource pt (wikitext do poema) |
| `macunaima.txt` | Macunaíma — Mário de Andrade (†1945) | Wikisource pt, ed. 1928 (18 caps. + Epílogo) |
| `vidas-secas.txt` | Vidas Secas — Graciliano Ramos (†1953, DP desde 2024) | Projecto Adamastor (ebook 2024, CC BY-SA 4.0; texto-fonte: 1ª ed. José Olympio, 1938) via archive.org |

Notas:
- As edições Gutenberg/Wikisource preservam a **ortografia original** da época
  (ex.: "annos", "Braz Cubas") — isso é fiel às primeiras edições.
- `vidas-secas.txt`: atribuição da edição — Projecto Adamastor
  (projectoadamastor.org), revisão de Ricardo Lourenço, licença CC BY-SA 4.0.
  Pequenos artefatos de OCR do trema (gü/qü) foram corrigidos manualmente.
- Obras dos demais autores da seção Literatura (Rachel de Queiroz, Carolina
  Maria de Jesus, Jorge Amado, Clarice Lispector, Ariano Suassuna, Drummond,
  João Cabral, Guimarães Rosa, Conceição Evaristo, Itamar Vieira Junior)
  **permanecem protegidas por direitos autorais** — para elas o sistema oferece
  apenas o resumo completo autoral (lib/resumos-completos.ts).
